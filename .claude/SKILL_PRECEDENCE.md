# Skill Precedence

When installed skills give conflicting guidance, resolve in this order:

1. The project specification and CLAUDE.md have highest priority.
2. Security and accessibility requirements override visual preferences.
3. The artistic scene specification overrides generic advice against:
   - gradients
   - glow
   - bloom
   - fog
   - chromatic effects
   - unconventional layout inside the scene canvas
4. Generic frontend-design advice applies to the editor and application shell.
5. Three.js advice applies to the WebGL scene runtime.
6. React and composition skills govern code architecture.
7. Web-quality skills govern performance, accessibility, and browser behavior.
8. Awesome UX skills govern flow design, user control, trust, and usability.
9. A skill may not silently broaden product scope.
10. When two skills conflict, document the conflict and follow the project specification.
